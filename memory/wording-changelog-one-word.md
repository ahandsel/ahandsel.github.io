# Use "Changelog" (one word) not "change log" (two words)

* Type: Wording
* Added: 2026-08-28
* Source: the owner's standing wording preference, imported on 2026-08-28 from a memory in one of the owner's private repositories

Write "changelog" as one word, and capitalize it as "Changelog" wherever the surrounding text calls for a capital.
Do not write it as the two words "change log".

The rule covers every reference to a changelog in this repository, including headings, labels, table cells, and body prose, in both language trees.

"Change log" is the older, traditional spelling.
Correct it to the one-word form on the next pass through a file that still carries it.
